# 桌面快捷方式助手

一个轻量 Windows 桌面小助手，用来收纳桌面上的 `.lnk`、`.url`、`.appref-ms` 快捷方式。默认界面使用 WPF，样式更接近软件助手：顶部操作区、搜索框、软件卡片宫格和真实程序图标。

## 使用

1. 双击 `start.bat` 启动。
2. 屏幕左下角会出现一个小的“助”图标。
3. 鼠标移入“助”图标会展开完整助手面板，鼠标移出面板会自动隐藏。
4. 按住胶囊图标拖动，松手后会自动吸附到当前屏幕最近的角落；面板会从该角向屏幕内侧展开。
5. 点击“一键收纳”，先勾选要收纳的桌面快捷方式，确认后程序会把选中的快捷方式移动到项目里的 `shortcuts` 文件夹，并在底部状态栏显示结果。
6. 助手窗口中只显示软件图标，单击图标即可启动。
7. 右键图标可以还原单个快捷方式，也可以点击“全部恢复”一次性还原。
8. 点击“一键回到桌面”可以快速显示 Windows 桌面。

## 固定到任务栏

1. 双击 `create-shortcut.bat`，它会创建带图标的“桌面软件助手”快捷方式。
2. 右键桌面或开始菜单里的“桌面软件助手”快捷方式，选择“固定到任务栏”。
3. 需要取消固定时，右键任务栏上的图标，选择“从任务栏取消固定”。

Windows 对脚本直接固定/取消固定任务栏限制比较多，所以这里采用系统推荐的快捷方式方式。

## 排查启动问题

如果双击 `start.bat` 没反应，改双击 `start-console.bat`，它会显示 PowerShell 报错信息。

当前默认启动的是 `desktop_assistant.ps1`，不依赖 Python。仓库里仍保留 `desktop_assistant.py` 作为 Python/Tkinter 版本，备用。

## 文件说明

- `desktop_assistant.ps1`：默认主程序，WPF 界面。
- `desktop_assistant.py`：Python/Tkinter 版本，备用。
- `start.bat`：无控制台窗口启动。
- `start-console.bat`：带控制台启动，方便排查错误。
- `create-shortcut.bat`：创建带图标的桌面和开始菜单快捷方式。
- `assets/app.ico`：程序图标，用于窗口和任务栏快捷方式。
- `shortcuts/`：收纳后的快捷方式存放位置。

## 注意

程序只移动快捷方式文件，不会删除桌面文件，也不会移动普通文件夹、文档或安装包。
